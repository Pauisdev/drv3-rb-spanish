# Resolute Rebellion's official spanish translation!

## Installation
Grab the latest release from the Releases page, place it on your `Mods` from `Reloaded-II` and make sure it shows a `+` before running.

## Building it yourself/Contributing
### Requirements
- Bash
- HarmonyTools (must be on path)
- DRV3 and Resolute Rebellion clean copies

You'll need to run `build.sh`, it'll ask for the path to both DRV3 and Resolute Rebellion. 
Output mod will be placed on a newly created folder called `out`.
